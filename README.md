# Uranus projects

Each project lives in its own folder:

| Folder | Project |
|---|---|
| [`menu-platform/`](menu-platform/) | Multi-restaurant QR menu platform (Next.js). See its [README](menu-platform/README.md) and [deploy guide](menu-platform/docs/DEPLOY.md). |

`.claude/skills/` holds shared Claude skills used across projects.

New projects: add a new top-level folder. On Netlify, each project is its own site with **Base directory** set to its folder.
